breakpoint — a multi-viewport dev browser, driven from the terminal

Usage: breakpoint <path> [flags]
       breakpoint <command> [flags]

Commands:
  <path> [--wait]                                                                Open the project for that repo, creating it the first time
  open <url> [--wait]                                                            Point every pane at a URL or a local port, opening a project if none is
  logs [--since <cursor|duration>] [--pane <pane>] [--level <level>] [--errors]  Print what the event log holds after a cursor or within a window of time
  changes [--since <cursor|duration>] [--pane <pane>]                            Print what went wrong and where the page went, after a cursor or within a window
  state [--wait]                                                                 Print the open project: name, repo, the URL its panes are on, and the panes
  quit                                                                           Shut the app down cleanly, releasing the single-instance lock

Flags:
  --json                                                                         Print the route payload as JSON on stdout and nothing else
  --no-launch                                                                    Exit 3 rather than starting the app if it is not running
  --wait                                                                         Block until every pane has loaded and is drawn at its declared size, for up to 30s
  --background                                                                   Start or hand off without bringing the window forward
  --verbose                                                                      Print diagnostics on stderr, where they cannot pollute stdout
  --help, -h                                                                     Print this help and exit 0

Examples:
  breakpoint .
  breakpoint . --wait --json
  breakpoint open 3000
  breakpoint open https://staging.example.com/cart --json
  breakpoint state --json | jq .project.panes
  breakpoint logs --since 12 --json
  breakpoint logs --errors --since 5m --json
  breakpoint changes --since 30s
  breakpoint quit
